# web-page

A premium animated luxury website template designed for high-end fashion, footwear, and lifestyle brands. Built with Tailwind CSS and GSAP, this template focuses on cinematic user experience, smooth transitions, and modern luxury aesthetics.

#This project is ideal for:

Shoe brands

Clothing boutiques

Watch brands

Luxury product landing pages

High-end portfolio or brand showcases

#✨ Features

Cinematic preloader animation

Smooth scroll-based reveal animations (GSAP + ScrollTrigger)

Luxury shutter transition system

Dark / Light mode toggle

Premium serif + modern sans-serif typography

Fully responsive layout

Clean and modern luxury UI

Easy to customize HTML structure

Tailwind CSS utility-based styling

#🛠️ Tech Stack

HTML5

Tailwind CSS (CDN)

GSAP 3

GSAP ScrollTrigger

#🎨 Customization Guide
Change Logo

Replace this file:
```
main logo.jpg
```

Or update this line in index.html:
```
<img src="main logo.jpg" alt="Logo">
```
Change Product Images

Replace these files:
```
perfect 2.jpg
shoe perfect.jpg
```

Or update:
```
<img src="perfect 2.jpg">
<img src="shoe perfect.jpg">
```
Change Text Content

Edit directly in index.html:

#Hero Title:
```
<h1>Manlystore</h1>
```

#Tagline:
```
<p>Step into Sovereignty</p>
```

#Product Names:
```
<h2>The Midnight</h2>
<h2>The Espresso</h2>
```
#Change Brand Colors

#Edit CSS variables in <style>:
```
:root {
  --bg: #0a0a0a;
  --text: #ffffff;
  --accent: rgba(255,255,255,0.1);
}
```

#Light mode:
```
.light-mode {
  --bg: #fcfcfc;
  --text: #000000;
  --accent: rgba(0,0,0,0.1);
}
```

#🌙 Dark / Light Mode

The template includes a built-in day/night mode toggle.
Users can switch themes using the Day Mode / Night Mode button in the navigation bar.

#🎞️ Animations

This project uses GSAP for:

Page UI transitions

All animation logic is located inside the <script> section in index.html.
